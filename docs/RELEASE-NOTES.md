## Cellar 1.1

**New look.** Home is now console-style: your game's art fills the window, Play is front and centre,
and your games sit in a row along the bottom. Use ← → to pick a game and Return to play.

**New**
- **Friends:** see which Steam friends are online or in a game, and chat with them. If they're
  playing something you have, there's a Play button right there.
- **Add to Dock:** each game can get its own Mac app icon (Applications › Cellar Games) for the Dock
  or Launchpad.
- **FPS counter:** Apple's performance overlay (frame rate, frame time, GPU) in Settings, or per game.
- **Game Mode:** Steam games now run as real Mac games, so macOS Game Mode kicks in when you go
  fullscreen. Smoother frame pacing and lower controller and AirPods latency.
- Games show their own name and icon in the Dock instead of "wine".

**Install or update**
Already have Cellar? It updates itself. New: download **Cellar.zip** below, drag it to Applications,
then **right-click → Open** the first time.

Needs macOS 26 or later and Apple Silicon. Cellar isn't affiliated with CodeWeavers, Valve or Apple.
