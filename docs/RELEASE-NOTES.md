## Cellar 1.3

**Cellar's overlay.** Press **Shift+Tab** in any game to see who's online, **Join** a friend, **Invite** friends or Force Quit. It's a native panel, so it can't crash your game. Change the key in Settings.

**One-click Join.** When a friend is in a game you can join, click **Join**, in the overlay or the Friends tab. Cellar starts the game with the right settings and puts you in their lobby. This works in games that use Steam's lobbies. Games with their own server browser are still joined inside the game.

**Smoother games.** Two fixes in the Wine engine target regular pauses: one about every 30 seconds, one when a game loads part of itself. They come from the Recall project, which measured the gains in Overwatch; your games may differ.

**Presets and more settings.** Each game has Quality, Balanced and Battery presets, plus an Advanced section: graphics backend, frame limit, FPS counter, Retina, Steam's overlay, launch options. Frame limits work on DXMT games; on D3DMetal games, use the game's own limit or vsync.

**Also**
- Steam's window stays closed while you play, which saves CPU, memory and battery. Change this in Settings.
- Cellar asks about the Battery preset when you press Play unplugged, on games where it can limit frames.
- Nuclear Option no longer hangs on Loading.
- "Running" status and Force Quit are reliable again.
- Game covers recover after a network that blocks Steam, like school Wi-Fi.
- You can drag the window by its top bar.

**Still new to testing:** Join and Invite haven't been tried between two real players yet. If one doesn't work, Cellar opens Steam's chat with that friend instead. Tell me what happened.

**Install or update**
Already have Cellar? It updates itself. New: download **Cellar.zip** below and drag it to Applications. Then open it, go to **System Settings → Privacy & Security**, and click **Open Anyway**.

Needs macOS 26 or later and Apple Silicon. Cellar isn't affiliated with CodeWeavers, Valve or Apple.
