## Cellar 1.0

Play Windows Steam games on your Apple Silicon Mac. Free, for friends.

**Install**
1. Download **Cellar.zip** below, unzip it, and drag **Cellar** into Applications.
2. The first time: **right-click Cellar → Open → Open** (it isn't signed with a paid Apple account).
   If macOS still refuses: System Settings → Privacy & Security → **Open Anyway**.
3. Click **Set Up** (about 1.5 GB, a few minutes), then sign in to Steam in the window that opens.
   This is Windows Steam inside Cellar, so it needs its own sign-in once, even if Mac Steam is signed in.
4. Install a game in Steam. It appears in Cellar's library. Press **Play**.

**What's inside**
- Wine 11 built from CodeWeavers' open-source CrossOver 26.3 release, with two small Cellar patches
  (Steam's window renders; one Dock icon for Steam).
- D3DMetal 3.0 for DirectX 11/12 games, DXMT 0.80 for DirectX 10/11, WineD3D for old games.
- Game fixes that update automatically: One More Lawn (and its demo), Counter-Strike 2.

**Good to know**
- Needs macOS 26 or later and Apple Silicon.
- Macs with 8 GB of memory get low-memory mode automatically (Steam's window closes while you play).
- Games with kernel anti-cheat (most BattlEye and Easy Anti-Cheat games) can't run on any Mac.
- Something stuck? Games menu → **Force Quit All Games** (⇧⌘K).

Cellar updates itself. It isn't affiliated with CodeWeavers, Valve or Apple.
