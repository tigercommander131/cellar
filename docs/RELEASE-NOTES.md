## Cellar 1.2

**Offline mode for school Wi-Fi.** Some networks block Steam, so it gets stuck signing in. Click your
Steam name at the top of Cellar → **Go Offline**, or use Settings → Steam → Offline mode. Games then
start with the sign-in Steam saved last time you were online. Switch back with **Go Online** at home.
The dot next to your name turns orange while you're offline.

Also new since 1.0: console-style home, Friends, Add to Dock, FPS counter and macOS Game Mode.

**Install or update**
Already have Cellar? It updates itself. New: download **Cellar.zip** below, drag it to Applications,
then **right-click → Open** the first time.

Needs macOS 26 or later and Apple Silicon. Cellar isn't affiliated with CodeWeavers, Valve or Apple.
